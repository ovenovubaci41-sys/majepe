# Majestic Roulette Analyzer v5 — таймер раунда + калибровка

## Новое
- Частое сканирование по умолчанию каждые 0.35 секунды.
- Настраиваемая длительность раунда, по умолчанию 15 секунд.
- Кнопка «Калибровка: 50 раундов»: записывает одно стабильное наблюдение каждые 15 секунд, начиная после первого полного интервала.
- Калибровка завершается после 50 наблюдений, затем программа показывает частоты и предварительную статистику.
- Повторные одинаковые цвета могут записываться как отдельные раунды, потому что записи создаются по таймеру, а не только при смене цвета.
- Записи помечаются «Авто»; их можно исправить вручную.

## Сборка
Замените `app.py` в GitHub на этот файл, сделайте Commit changes, затем запустите GitHub Actions workflow и скачайте Artifact.

## Важное ограничение
Таймер 15 секунд — заданное пользователем предположение, а не синхронизация с сервером игры. Если старт программы не совпадает с реальным циклом или выбранная ячейка не показывает итог текущего раунда, возможен сдвиг и неверные записи. Перед использованием вероятностей проверьте все 50 результатов и исправьте ошибки. 50 раундов дают лишь грубые частоты; они не гарантируют прогноз следующего результата.
